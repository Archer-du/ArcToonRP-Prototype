# 2026-04-07 工作日志

## Step A 问题排查与修复

### 排查出的问题
1. **P0 编译错误**：5 个 Pass 文件（TransparentPass/OpaquePass/OrderedDualFacePass/DepthPeelingPass/WeightedAveragePass）引用了已删除的 `shadowMapHandle.directionalShadowMatrices` 字段
2. **P0 时序逻辑错误**：`LightingPass.Render()` 中 `SetBufferData(LightData)` 在 `RenderShadowMap()` 之前执行，`SetBufferData` 录制时拷贝数组快照，导致 normalBiasScale 回写永远不会被 GPU 看到
3. **P2 死代码**：`SpotShadowBufferData.cs.hlsl` 和 `PointShadowBufferData.cs.hlsl` 残留

### 修复方案：normalBias 拆分为 per-light × per-tile

**核心设计**：
- `light.shadowNormalBias`（per-light 配置值）→ 存入 `LightBufferData.shadowData.z`（PerLightDataCollector 阶段写入）
- `texelSize * FilterSize * sqrt(2)`（per-tile 因子）→ 存入 `ShadowTileBufferData.atlasData.w`（ShadowMapRenderer.RenderSplitTile 阶段写入）
- Shader 端：`normalBias = normal * distanceToLightPlane * shadowData.z * tileData.atlasData.w`
- 彻底移除 ShadowMapRenderer 对 LightBufferData 的引用和回写，消除时序依赖

### 具体改动
- ✅ 5 个 Pass 文件：`directionalShadowMatrices` → `directionalShadowData`
- ✅ `PerLightDataCollector.cs`：Spot/Point 的 `shadowData.z` 改为直接写入 `light.shadowNormalBias`
- ✅ `ShadowMapRenderer.cs`：移除 `spotLightBufferData`/`pointLightBufferData` 字段和 Initialize 参数；Spot/Point 的 RenderSplitTile 改为计算 normalBiasFactor 写入 `ShadowTileBufferData.atlasData.w`
- ✅ `LightingPass.cs`：恢复 Initialize 调用为无 LightBufferData 参数版本
- ✅ `ShadowTileBufferData.cs`：构造函数新增 `normalBiasFactor` 参数，存入 `atlasData.w`
- ✅ `SpotLight.hlsl`/`PointLight.hlsl`：normalBias 改为 `shadowData.z * tileData.atlasData.w * distanceToLightPlane`
- ✅ 删除 `SpotShadowBufferData.cs.hlsl` 和 `PointShadowBufferData.cs.hlsl` 死代码
- ✅ 更新 `PerLight_PCSS_LightSize.md` 设计文档为第六版

```
.w = lightSize (per-light PCSS light size)
```

## BitPacking 通用工具抽取

### 新建文件
- `Runtime/Utils/Extensions/BitPackingExtensions.cs` — C# 端通用 bit packing 工具

  - `Unpack4x8`：4 × 8-bit 解包

# ArcToonRP-Prototype

The prototype of ArcToon render pipeline, only for learning and testing.

## Branch Strategy

- `sample_project` — Sample project branch, contains a Unity sample project using ArcToon RP
- `develop` — Development branch

## Submodule

The render pipeline core code is stored as a Git Submodule in the `Packages/com.arctoon.render-pipeline` directory, corresponding to the following branches in the repository:

- `arctoon/0.1.0` — Stable release branch
- `arctoon/develop` — Main development branch

Git URL to install this package:
```
https://github.com/Archer-du/ArcToonRP-Prototype.git#arctoon/0.1.0
```
